# DHL Shipment Analytics using EDA with Streamlit Dashboard

## 📌 Project Overview
This project analyzes DHL shipment data using Exploratory Data Analysis (EDA) and Machine Learning. It predicts shipment delays and provides an interactive Streamlit dashboard for visualization and insights.

## 🚀 Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization
- Logistic Regression
- Random Forest Classifier
- Confusion Matrix
- ROC Curve & ROC-AUC Score
- Interactive Streamlit Dashboard

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit

## 📂 Project Structure
```
app.py
DHL_Project.ipynb
DHL_Shipment_Data.csv
requirements.txt
Project_Documentation.pdf
README.md
```

## ▶️ How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📊 Machine Learning Models
- Logistic Regression
- Random Forest Classifier

## 📈 Evaluation Metrics
- Accuracy Score
- Confusion Matrix
- ROC Curve
- ROC-AUC Score

## 🎯 Objective
To analyze DHL shipment data, identify important patterns, and predict shipment delays using machine learning techniques.
